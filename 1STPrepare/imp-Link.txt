At ~3 years experience, companies expect you to **choose the right libraries—not just use many**. The goal is productivity + scalability + performance.

Here are the **most useful 3rd-party libraries (widely used in industry)** with when and why to use them 👇

---

# 🚀 1. API & Server State Management

### ⭐ Must-have

* **Axios**
  👉 Simple API calls, interceptors, error handling

* **TanStack Query**
  👉 Caching, auto refetch, loading states (industry favorite)

📌 Use this instead of manually managing API state in useEffect

---

# 🧠 2. Global State Management

### ⭐ Most used

* **Redux Toolkit**
  👉 Enterprise apps, predictable state

* **Zustand**
  👉 Lightweight & easy (modern choice)

📌 Trend: Many companies prefer **Zustand + React Query combo**

---

# 🎨 3. UI Component Libraries

### ⭐ Save tons of time

* **Material UI**
* **Ant Design**
* **shadcn/ui**

📌 Use for:

* Forms
* Tables
* Modals
* Dashboards

# 🧾 4. Forms & Validation

### ⭐ Must know

* **React Hook Form**
* **Yup** / **Zod**

📌 Why:

* Better performance than controlled forms
